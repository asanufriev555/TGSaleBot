# Каталог проектов: трансформаторы (ГОСТ Р 52719)

Мини-приложение для Windows 7+: сканирует папку (в том числе сетевую `\\сервер\папка`) со вложенными
папками, находит технические задания/спецификации на поставку трансформаторов и строит базу проектов
с разбивкой **по типам трансформаторов** и **по годам**.

## Технологии
- Python **3.8** (последняя версия, работающая на Windows 7), только стандартная библиотека: `tkinter` + `sqlite3`.
- База — один файл **SQLite** (`transformers.db`): можно положить на сетевой диск, открывается любым SQLite-просмотрщиком.
- Чтение `.docx`/`.xlsx` встроено; `.txt/.csv` — встроено; `.doc/.xls` — грубое извлечение текста;
  `.pdf` — при установленном `pypdf` (`py -3.8 -m pip install pypdf`), иначе PDF учитывается только по имени.

## Запуск
`run.bat` или `py -3.8 main.py`. Один exe без установки Python: `build_exe.bat` → `dist\TransformerCatalog.exe`.

## Как пользоваться
1. Вкладка **Сканирование**: введите адрес папки (или «Обзор…») → «Сканировать». Проектом считается подпапка
   первого уровня (глубина меняется в параметрах `project_depth`).
2. Вкладка **Проекты**: фильтры по году/типу/поиск, добавление, правка (двойной щелчок), удаление,
   «Подробнее» (файлы и недостающие пункты ГОСТ), экспорт в CSV для Excel. Правленные вручную записи
   помечаются «Ручн.» и повторным сканированием не перезаписываются.
3. Вкладка **По типам и годам**: дерево «Тип → Год → Проекты» или «Год → Тип → Проекты».
4. Вкладка **Параметры**: настройки сканирования, правила определения типа (категория ← регулярное
   выражение по обозначению ТДН/ТМГ/ТСЗ… или тексту) и чек-лист ГОСТ Р 52719 — всё редактируется в интерфейсе.

## Как определяются данные
- **Тип** — по обозначению трансформатора в ТЗ (ТДН-16000/110, ТМГ-1000/10…) по таблице правил.
- **Мощность/напряжение/количество/охлаждение** — регулярными выражениями из текста ТЗ.
- **Год** — из названия папки/файла (20xx), иначе по дате изменения файлов.
- **ГОСТ Р 52719** — для каждого ТЗ проверяется наличие в тексте обязательных параметров (мощность, напряжения,
  группа соединения, потери ХХ/КЗ, uк, ток ХХ, охлаждение, РПН/ПБВ, климатическое исполнение, изоляция/испытания,
  ссылка на стандарт). Это **автоматическая подсказка, а не заключение о соответствии** — чек-лист и шаблоны
  нужно сверить с актуальной редакцией стандарта и подправить во вкладке «Параметры».
